Netzwerk (Lobby)

Gemeinsame Eingangstuer fuer alle Server ueber einen transparenten Router. Aktuell: {{ network_mode }} (Quelle: {{ "UI" if network_mode_source == "ui" else "Standard" }}).

  • off – kein gemeinsamer Eingang; jeder Server auf eigenem Port.
  • gateway – transparenter Router: eine Adresse leitet per Hostname (<alias>.<domain>) direkt zum passenden Server. Jeder Typ, jede Version, Direktverbindung bleibt erhalten. Kein begehbarer In-Game-Hub.

Oeffentlicher Gateway-Eingang. Nur diesen (zusaetzlich zu den direkten Server-Ports) freigeben.

Fuer die Adressen <alias>.<domain>.

Im gateway-Modus laufen ALLE Server ganz normal weiter (jeder Typ, jede Version, parallel) und bleiben direkt auf ihrem Port erreichbar. Das Gateway leitet zusaetzlich <alias>.<domain> transparent zum passenden Server. Pro Server unter Server → Einstellungen → Gateway-Routing einen Alias vergeben. Werte gelten auch via MCSM_NETWORK_PORT/MCSM_NETWORK_DOMAIN in der .env.

Lobby automatisch einrichten

Legt mit einem Klick einen fertigen Paper-Lobby-Server (stabiles 1.21.x) an, markiert ihn als Gateway-Default (blanke Domain landet dort), setzt eine ruhige Lobby-Welt und installiert die begehbare Transfer-Lobby (Plugin MCSMLobby). Setzt den Netzwerk-Modus auf gateway. Danach nur noch starten.

Begehbare Lobby (ab Client 1.20.5): In der Lobby – Kompass (Rechtsklick) oeffnet das Server-Menue, alternativ /server <alias>, /hub. Schild: Zeile 1 [server], Zeile 2 der Alias. Begehbare Portale traegst du in plugins/MCSMLobby/config.yml unter regions ein. Die Server-Liste im Menue erzeugt der Manager automatisch aus den Gateway-Aliassen – funktioniert fuer jeden Servertyp.

„Transfer-Menue neu erzeugen" schreibt die Server-Liste des Plugins auf allen Gateway-Servern neu (Lobby-Menue + /lobby auf den anderen). Bei laufenden Servern danach neu starten, damit das Plugin die Aenderung laedt.

Multi-Version-Lobby (ViaVersion)

Standardmaessig kann sich nur ein Client der exakt gleichen Version wie die Lobby verbinden – sonst „Outdated client/server". Dieser Knopf laedt ViaVersion, ViaBackwards und ViaRewind in die Lobby, damit sich Clients jeder Version (neuer wie aelter, auch modded wie ATM10) mit der Lobby verbinden koennen. Download von Modrinth passend zur Lobby-Version.

Danach die Lobby neu starten. Hinweis: Via macht die Lobby fuer alle Versionen erreichbar. Ein transferierter Spieler landet dann auf dem Zielserver – der sollte moeglichst die passende Version sprechen (oder ebenfalls Via haben).
