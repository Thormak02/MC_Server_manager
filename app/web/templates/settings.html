Netzwerk (Lobby)

Gemeinsame Eingangstuer fuer alle Server ueber einen Velocity-Proxy. Aktuell: {{ network_mode }} (Quelle: {{ "UI" if network_mode_source == "ui" else "Standard" }}).

  • off – kein gemeinsamer Eingang; jeder Server auf eigenem Port.
  • gateway – transparenter Router: eine Adresse leitet per Hostname (<alias>.<domain>) direkt zum passenden Server. Jeder Typ, jede Version, Direktverbindung bleibt erhalten. Kein begehbarer In-Game-Hub.
  • velocity – echter Proxy mit begehbarer Lobby (/server/Portal, ViaVersion) – aber nur Paper/Purpur-Server, nicht direkt erreichbar.

Oeffentlicher Port (Velocity-Eingang). Nur diesen nach aussen freigeben.

Fuer Direktadressen <name>.<domain>.

Leer = automatisch neueste stabile.

Lädt ViaVersion/-Backwards/-Rewind auf den Proxy, damit Clients verschiedener Versionen verbinden können.

Im velocity-Modus laufen die Backend-Server in online-mode=false und duerfen nur ueber Velocity erreichbar sein – nach aussen ausschliesslich den Netzwerk-Port ({{ network_port }}) freigeben. Pro Server unter Server → Einstellungen als Netzwerk-Backend markieren. Werte gelten auch via MCSM_NETWORK_PORT/MCSM_NETWORK_DOMAIN in der .env (die Einstellungen hier ueberschreiben die ENV-Werte).

Lobby automatisch einrichten

Legt mit einem Klick einen fertigen Paper-Lobby-Server (stabiles 1.21.x) an, markiert ihn als Netzwerk-Lobby (Sleep aus), setzt eine ruhige Lobby-Welt und installiert das Server-Auswahl-Plugin ServerSelector. Danach nur noch starten. Setzt den Netzwerk-Modus auf velocity.
