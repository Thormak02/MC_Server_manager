{# Spielerkopf vor einem Namen. Die Skin-Datei kommt vom Manager (/api/avatar/...), nicht von einem Fremddienst - sonst wuerde der Browser jedes Betrachters seine IP an Dritte liefern (derselbe Sachverhalt wie bei den Google-Fonts-Abmahnungen 2022). Den Kopf schneidet .player-head per background-position aus der Skin-Datei aus; die zwei gleichen URLs sind die zwei Lagen (Huthaut ueber Gesicht), der Browser laedt die Datei trotzdem nur einmal. avatar_schluessel(uuid, name) waehlt den Schluessel: echte Mojang-UUID bevorzugt, bei einer Offline-Mode-UUID der Name, bei Unbrauchbarem gar kein Kopf. #} {% macro kopf(schluessel, ersatz=None) -%} {%- set key = avatar_schluessel(schluessel, ersatz) -%} {%- if key -%} {%- set adresse = '/api/avatar/' ~ key -%} {%- endif -%} {%- endmacro %} {# Kopf + Name als eine Einheit, damit beide zusammen umbrechen. `schluessel` ist die UUID (falls vorhanden), `anzeige` dient als Rueckfall. #} {% macro name_mit_kopf(anzeige, schluessel=None) -%} {{ kopf(schluessel if schluessel is not none else anzeige, anzeige) }}{{ anzeige }} {%- endmacro %}
